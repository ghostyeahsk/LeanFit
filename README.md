# LeanFit 薄肌计划 — 男性每日锻炼微信小程序

一款面向男性的原生微信小程序，聚焦打造**穿衣显瘦、脱衣有肉**（低体脂、宽肩倒三角、清晰腹肌线条）的薄肌身材。

## 核心功能

1. **首次进入建档（Onboarding）**：录入身高、体重、年龄、每日可锻炼时间段（起止时间自动算时长）与训练场景（居家徒手 / 居家哑铃 / 健身房器械），实时测算 BMI、BMR、TDEE 与薄肌阶段（精瘦增肌 / 薄肌塑形 / 刷脂留肌）。
2. **每周薄肌分化计划**：周一至周日科学分化（上胸+三头 / 倒三角背+二头 / 腹肌+HIIT / 主动恢复拉伸 / 3D宽肩+核心 / 下肢促睾 / 完全休息），支持一键切换训练场景实时更新动作方案。
3. **每日薄肌健身餐**：自动识别训练日（中高碳）与休息日（低碳），根据每日目标热量等比换算四餐食材克数，支持单餐「换一换」与饮食打卡。
4. **每日锻炼计划任务**：展示当日锻炼时间段提醒、屏幕防息屏常亮、逐组记录负重与次数（自动带入上次训练数据）、组间休息倒计时（`+15s` / `+30s` / 跳过 + 震动提醒）、MET 科学热量估算与练后 RPE 体感反馈。
5. **GitHub 风格打卡热力图**：在「我的」页展示近 26 周 5 档青绿色阶打卡热力图（`Less -> More`），点击任意日期方块查看当日训练主题、完成组数、热量消耗、饮食餐数与 RPE 体感。
6. **微信云开发（CloudBase）同步 + 离线降级**：未配置云环境 ID 时默认以本地存储模式开箱运行；填入 `CLOUD_ENV_ID` 并部署云函数后即可多端云同步。

## 快速开始（微信开发者工具）

1. 打开 **微信开发者工具**，点击「导入项目」，选择本项目根目录 `leanfit-miniprogram`。
2. `AppID` 可先选择「测试号」直接本地预览全部功能，或填入您自己的微信小程序 AppID。
3. 编译运行后将自动进入建档引导页。

## 开启微信云开发（可选）

1. 在微信开发者工具顶部点击 **云开发**，开通并创建一个云环境，复制您的环境 ID。
2. 打开 `miniprogram/app.js`，将环境 ID 填入：
   ```js
   const CLOUD_ENV_ID = '你的云环境ID';
   ```
3. 在云开发控制台 -> **数据库** 中新建以下集合：
   - `users`
   - `plans`
   - `checkins`
4. 在开发者工具左侧 `cloudfunctions/` 目录下，分别右键 `login`、`syncProfile`、`submitCheckin`，选择 **上传并部署：云端安装依赖**。
